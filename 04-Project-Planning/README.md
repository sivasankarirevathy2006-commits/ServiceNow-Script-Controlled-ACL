# Phase 4: Project Planning

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Project Objective
To implement field-based record access control using ServiceNow ACL scripts.

## Project Activities
1. Understand project requirements.
2. Prepare the ServiceNow development environment.
3. Identify the target table and field.
4. Configure the required ACL.
5. Develop and configure the access control script.
6. Test access using appropriate user accounts.
7. Capture screenshots of implementation and results.
8. Prepare project documentation and demonstration video.
