# Phase 2: Requirement Analysis

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Functional Requirements
1. Create an Access Control Rule (ACL) in ServiceNow.
2. Use a script to evaluate the specified field value.
3. Allow authorized users to access records based on the defined condition.
4. Restrict access when the condition is not satisfied.
5. Test the access behavior with different user roles and field values.

## Software Requirements
- ServiceNow instance
- Web browser
- ServiceNow administrator access

## Expected Outcome
Record access should follow the configured ACL conditions
