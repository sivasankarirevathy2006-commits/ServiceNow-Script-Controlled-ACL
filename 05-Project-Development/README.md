# Phase 5: Project Development

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Development Environment
ServiceNow Platform

## Development Overview
The project involves configuring Access Control Lists (ACLs) and using scripts to control record access based on specified field values.

## Development Activities
1. Access the ServiceNow development instance.
2. Identify the target table and relevant field.
3. Configure the required Access Control Rule.
4. Define the applicable roles and access conditions.
5. Implement the ACL script according to the project requirements.
6. Save and validate the configuration.
7. Capture screenshots of the actual implementation.
