# Phase 7: Project Documentation

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Introduction
This project focuses on controlling access to ServiceNow records using script-based Access Control Lists.

## Objective
To implement record-level access control based on configured field values and user permissions.

## Technology Used
- ServiceNow Platform
- Access Control Lists (ACL)
- JavaScript-based ACL scripting

## Project Modules
1. Requirement Analysis
2. ACL Configuration
3. Script Implementation
4. Access Validation
5. Testing and Documentation

## Project Workflow
User Access Request → ACL Evaluation → Script Condition Check → Access Decision

## Expected Benefits
- Controlled access to records
- Improved data confidentiality
